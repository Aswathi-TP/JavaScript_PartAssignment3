# JavaScript PartAssignment3

## Project Description

This repository contains JavaScript practical assignments completed as part of the Software Testing course.

The assignment covers JavaScript functions, arrow functions, control flow, array methods, and asynchronous JavaScript concepts.

## Tasks Included

### Task 1: Functions, Arrow Functions & Control Flow
- Created a regular function to calculate student results.
- Used an arrow function to display student names and results.
- Used an array to store student details.
- Used a 'for...of' loop to process each student. 

### Task 2: Arrays & Array Methods
- Used 'forEach()' to display student details.
- Used 'map()' to create an array containing student names.
- Used 'filter()' to find students who scored 80 or above.

### Task 3: Asynchronous JavaScript – Theory
- Explained Callbacks and their usage.
- Explained Promises and their three states: Pending, Fulfilled, and Rejected.
- Explained Async/Await.
- Described the advantages of Async/Await.

## Technologies Used

## Execution Steps

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following commands:

**Task 1:**

node task1_functions.js


**Task 2:**

node task2_array.js
